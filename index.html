            02
            
RAG y Document Intelligence

            

              
reto
Conectar los LLMs con datos propios —bases de datos, APIs y documentos— para que respondan con información real.

              
decisión

RAGQdrantEmbeddingsNemotron ParseFastAPI

          


          

            03
            
Extracción documental con LLMs on-premise

            

              
problema
Documentos técnicos complejos con información clave atrapada en texto no estructurado, difícil de explotar a escala.

              
decisión
Pipeline completo con LLMs on-premise: OCR y preprocesado, chunking, inferencia con Ollama en multi-GPU (Gemma, Qwen, DeepSeek), Structured Outputs con validación automática y postprocesado.

              
resultado
Precisión, consistencia y reducción de errores mejoradas de forma iterativa mediante prompt engineering, testing y validación manual.

            

            
OllamaStructured OutputsOCRChunkingMulti-GPU

          


          

            04
            
Benchmarking de LLMs

            

              
problema
Elegir modelo local a ciegas: sin datos comparables de calidad ni de coste real por inferencia.

              
decisión
Sistema de benchmarking que mide calidad de outputs, latencia, throughput y consumo de GPU por modelo y configuración.

              
resultado
Comparar modelos con datos de calidad, latencia, throughput y consumo de GPU, no con intuición.

            

            
PythonGPU profilingEvaluación

          


          

            05
            
Dashboard de inspecciones de ascensores

            

              
problema
Gestionar las inspecciones de ascensores desde un único dashboard.

              
decisión
Aplicación a medida con FastAPI y SQLite, integrando la API de Anthropic para las capacidades de IA. Stack ligero, fácil de desplegar y mantener.

              
resultado
Aplicación funcional, con visión de convertirla en producto comercializable.

            

            
FastAPISQLiteAnthropic API
