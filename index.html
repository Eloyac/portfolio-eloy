              Atrebo
              en producción interna
            

            
Extracción documental con LLMs on-premise

            

              
problema
Documentos técnicos heterogéneos con información crítica atrapada en PDFs, imposible de explotar a escala manualmente.

              
decisión
Pipeline completo on-premise por privacidad y coste: OCR y preprocesado, chunking, inferencia con Ollama en multi-GPU (Gemma, Qwen, DeepSeek) y postprocesado hacia JSON estructurado.

              
resultado
Sistema en uso interno, con precisión y consistencia mejoradas iterativamente mediante prompt engineering, testing y validación manual.

            

            
OllamaOCRChunkingMulti-GPU

              en uso continuo
            

            
Benchmarking de LLMs

            

              
problema
Elegir modelo local a ciegas: sin datos comparables de calidad ni de coste real por inferencia.

              
decisión
Sistema de benchmarking que mide calidad de outputs, latencia, throughput y consumo de GPU por modelo y configuración.

              
resultado
Las decisiones de qué modelo corre en producción se toman con datos, no con intuición.

              cliente real · en evolución
            

            
Dashboard de inspecciones de ascensores

            

              
problema
Un negocio real gestionando inspecciones de ascensores con procesos manuales dispersos.

              
decisión
Aplicación a medida con FastAPI y SQLite, integrando la API de Anthropic para las capacidades de IA. Stack deliberadamente simple: fácil de desplegar, fácil de mantener.

              
resultado
En uso por el cliente, con hoja de ruta para convertirlo en producto comercializable para más empresas del sector.

Pipeline de contenido automatizado

            

              
reto
¿Hasta dónde se puede automatizar la producción de contenido de principio a fin? Mi laboratorio personal para averiguarlo.

              
decisión
Pipeline propio que orquesta n8n, ElevenLabs, FFmpeg y CapCut, con un bot de Telegram desarrollado a medida para notificaciones del sistema.

              
resultado
Dos canales de YouTube operando de forma automatizada: ConfessedStories (inglés) y TerrorSinFiltro (español).
